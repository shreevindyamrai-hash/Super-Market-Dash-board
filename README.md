# Superstore Sales Dashboard | Power BI

## 📊 Project Overview

The **Superstore Sales Dashboard** is an interactive data visualization project developed using Microsoft Power BI. It analyzes superstore sales performance, revenue, profit, customer activity, order trends, product categories, and shipping methods.

The dashboard helps users explore business performance and identify trends through interactive charts, KPI cards, and filters.

## 🎯 Project Objectives

- Analyze sales and revenue performance.
- Track total orders, sales, profit, and customers.
- Compare yearly revenue and sales trends.
- Understand product category performance.
- Analyze orders across different states and cities.
- Evaluate profit distribution by shipping method.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **CSV / Excel datasets** – Data source.
- **Power Query** – Data cleaning and transformation, if used in the project.
- **DAX** – Calculated measures and KPIs, if used in the project.

## 📈 Dashboard Features

### Page 1: Sales Overview
- KPI cards for total orders, profit, revenue, customers, and sales.
- Total orders by day.
- Monthly order and sales trends.
- Total profit by year.
- Revenue analysis by order ID.
- City filter for interactive exploration.

### Page 2: Sales and Profit Analysis
- Yearly revenue comparison.
- Sales distribution by product category.
- Total orders by state.
- Customer distribution by city.
- Profit analysis by shipping mode.

## 💡 Key Insights

The dashboard provides a visual way to explore:
- Changes in revenue across different years.
- The contribution of Office Supplies, Furniture, and Technology to sales.
- Differences in order volumes across states.
- Customer distribution across cities.
- Profit contribution from different shipping methods.

## 🚀 How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `sample-superstore.pbix`.
4. If prompted, update the dataset path to the CSV file included in the repository.
5. Explore the dashboard pages, charts, and available filters.
